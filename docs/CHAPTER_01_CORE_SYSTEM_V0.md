# 《寻仙问道：悟道山试炼》第一章核心系统 V0 边界定稿

本文档用于定义第一章 Web Demo 的核心系统 V0 边界。第一章定位为“全游戏核心系统的最小骨架切片”，不是普通新手教学，也不是全量系统实现。后续 Codex 开发任务必须引用本文档，并严格遵守 P0 范围与后置红线。

# 《寻仙问道：悟道山试炼》

# 第一章核心系统 V0 边界定稿

## 一、第一章定位

第一章不再定义为“普通新手教学 Demo”，也不是“纯演出垂直切片”。

第一章定位为：

> **全游戏核心系统的最小骨架切片。**

它要做到：

* Web 端可落地；
* 第一章体验闭环；
* 能展示未来 3A 修仙动作 RPG 的系统潜力；
* 每个核心系统都有可见雏形；
* 但不做复杂养成、矩阵、升级、自由组合和运营型内容。

第一章的目标不是把系统做满，而是证明：

> 这个世界的底层规则已经存在。
> 玩家不是在玩一个换皮动作小游戏，而是在体验一个修仙 ARPG 系统雏形。

---

## 二、总设计必须纳入的核心系统

以下系统全部进入《寻仙问道》的完整游戏总设计：

1. 五行元素反应
2. Q 灵气传导
3. 武器品质 / 耐久 / 更替
4. 命书行囊 / 背包
5. E 神通
6. 命格被动
7. 拘灵收服
8. Boss 破势与仙门考核

这些系统不是第一章临时彩蛋，而是完整游戏的核心骨架。

但第一章只做这些系统的 V0 雏形。

---

## 三、第一章 P0 核心原则

第一章 P0 采用以下原则：

> **系统必须可见，深度必须克制。**

具体规则：

1. 只证明规则存在，不做全量内容。
2. 只做第一章固定场景内可用，不做全局通用开放系统。
3. 只做固定数值，不做复杂成长公式。
4. 只做少量示例，不做内容堆叠。
5. 只做战斗闭环需要的最小交互，不做运营型养成。

一句话：

> 每个系统只露一块骨头，让人看见未来能长成完整身体。

## 四、元素反应 V0

### 定位

元素反应是世界规则，第一章必须展示。

但第一章不做完整五行矩阵，不做复杂元素状态叠加。

### 第一章 P0 做法

第一章采用：

> **每个灵根至少有一个可见反馈，核心反应先做 2-3 个。**

这样既能保证五种灵根玩家都有体感，又不会一次性做完整矩阵。

### P0 反应建议

| 灵根 | 第一章反馈 / 反应              |
| -- | ----------------------- |
| 金  | 金击土石，裂甲破势，对石傀破势值提高      |
| 木  | 木遇水，木棍短暂延长，或触发生息回血      |
| 水  | 水遇火，蒸汽冲击，造成小范围冲击 / 短暂遮蔽 |
| 火  | 火遇木，燃爆，造成小范围爆发伤害        |
| 土  | 土引地脉，触发土刺 / 短暂护体        |

其中优先打磨 2-3 个核心反应：

1. 火 + 木：燃爆
2. 水 + 火：蒸汽冲击
3. 金 + 土：裂甲破势

### 第一章不做

* 不做完整 5x5 元素矩阵；
* 不做双元素持续叠加；
* 不做复杂元素状态；
* 不做连锁爆炸；
* 不做元素克制表 UI；
* 不做环境持续地形改造。

## 五、Q 灵气传导 V0

### 定位

Q 不是普通技能键。

Q 定义为：

> **引气 / 传导键。**

玩家按 Q，本质是调动体内灵气，并传导到当前载体。

### 第一章 P0 做法

Q 可传导到：

1. 当前武器；
2. 固定环境元素；
3. 特定场地机关；
4. 后续拾取的新武器。

### 体验逻辑

玩家按 Q 后：

* 当前武器进入附灵状态；
* 木棍 / 残兵出现当前主灵根五行光效；
* 下一次攻击带灵根反馈；
* 若攻击命中环境元素，则触发对应元素反应；
* 若攻击命中 Boss 强势状态，则增加破势值。

### 第一章不做

* 不做多种 Q 模式；
* 不做 Q 技能列表；
* 不做复杂消耗曲线；
* 不做灵气传导升级；
* 不做法宝 / 阵法传导。

## 六、武器系统 V0

### 定位

武器系统是未来完整游戏的重要骨架。

第一章要证明：

> 武器不是贴图，武器可以更替，可以承载灵气，可以损毁。

### 第一章 P0 做法

第一章做：

1. 当前武器数据；
2. 武器名称；
3. 武器品质；
4. 基础伤害；
5. 耐久字段；
6. 剧情折断；
7. 固定拾取武器；
8. 新武器可以继续 Q 附灵。

### 第一章武器示例

| 武器          | 品质       | 作用                    |
| ----------- | -------- | --------------------- |
| 凡木棍         | 凡品       | 初始武器，伤害低，附灵反馈明显       |
| 石傀断臂 / 山门旧剑 | 伪灵品 / 残品 | Boss 阶段拾取武器，攻击更重，破势更强 |

### 耐久展示

采用弱展示：

* 数据层有耐久；
* UI 可以不显示完整耐久条；
* 可以通过裂纹、音效、旁白表现木棍损耗；
* Boss 特定阶段触发折断。

### 第一章不做

* 不做随机掉落；
* 不做多武器自由切换；
* 不做武器背包对比；
* 不做锻造；
* 不做强化；
* 不做词条；
* 不做修理；
* 不做武器等级养成。

## 七、命书行囊 / 背包 V0

### 定位

第一章需要让玩家感受到：

> 我获得的东西不是消失了，而是被命书 / 行囊记录了。

但第一章不做复杂传统背包。

### 第一章 P0 做法

采用：

> **命书行囊只读面板。**

可以按 Tab / C 打开。

展示内容：

1. 当前武器；
2. 当前灵根；
3. 当前命格；
4. 当前神通；
5. 当前拘灵战利品；
6. 试炼物品记录。

### 推荐命名

不建议直接叫“背包”。

推荐叫：

> 命书行囊
> 或
> 试炼行囊

这样更符合修仙世界观。

### 第一章不做

* 不做格子拖拽；
* 不做整理；
* 不做丢弃；
* 不做使用道具；
* 不做合成；
* 不做分解；
* 不做交易；
* 不做扩容；
* 不做装备对比。

## 八、E 神通 V0

### 定位

E 是主动神通键。

Q 是引气传导，E 是神通释放。

两者区别：

| 按键 | 定位           |
| -- | ------------ |
| Q  | 引气 / 附灵 / 传导 |
| E  | 主动神通 / 爆发技   |

### 第一章 P0 做法

第一章做：

> **一个神通框架，五行轻量差异。**

也就是：

* E 可以释放当前神通；
* 不做 Ctrl + E 切换；
* 不做多个神通栏；
* 不做神通升级；
* 不做技能树；
* 可以根据主灵根改变颜色、特效和轻量效果。

### 五行神通 V0 建议

| 灵根 | 神通表现             |
| -- | ---------------- |
| 金  | 金锋破障：前方破势一击      |
| 木  | 青木生息：回复生命并震开近身敌人 |
| 水  | 水影流转：短位移 / 短暂无敌  |
| 火  | 赤焰爆发：前方范围伤害      |
| 土  | 厚土护身：短暂护盾 / 减伤   |

第一轮实现时，可以先统一逻辑：

> 灵气爆发，颜色和轻量效果随灵根变化。

后续再逐步分化五系。

### 第一章不做

* 不做 Ctrl + E 切换；
* 不做多个神通；
* 不做神通升级；
* 不做冷却缩减养成；
* 不做连招神通；
* 不做神通树。

## 九、命格被动 V0

### 定位

命格是角色被动，是五问定心进入战斗的另一条路径。

灵根影响主动表现，命格影响角色底层倾向。

### 第一章 P0 做法

第一章做：

> **五系基础被动，自动生效。**

不需要玩家主动操作，不做复杂 UI，只在命书行囊中显示描述。

### 命格被动建议

| 倾向 | 被动                     |
| -- | ---------------------- |
| 金  | 破势伤害略高 / 攻击略快          |
| 木  | 缓慢回血 / 回复效果提高          |
| 水  | 灵气恢复略快 / 闪避冷却略短        |
| 火  | 对硬直目标伤害略高 / 连续命中后下一击增强 |
| 土  | 受到伤害略低 / 抗击退略高         |

### 第一章不做

* 不做命格树；
* 不做命格升级；
* 不做多被动叠加；
* 不做命格选择界面；
* 不做复杂数值成长；
* 不做隐藏分支。

## 十、拘灵 V0

### 定位

拘灵是未来完整游戏的重要成长系统。

第一章要证明：

> Boss 不是单纯死亡，而是可以被命书收录，成为未来修行资源。

### 第一章 P0 做法

第一章做：

1. Boss 死亡后残灵出现；
2. 命书翻开；
3. 土行残灵被吸入命书；
4. 系统提示获得【土行石傀残灵】；
5. 命书行囊中可查看战利品卡片；
6. 卡片描述未来用途。

### 文案示例

> 【土行石傀残灵】
> 悟道山守门石傀遗留的土行残灵。
> 蕴有厚土之气，未来可用于炼器、法宝凝形、神通参悟或拘灵化身。

### 第一章不做

* 不做拘灵召唤；
* 不做变身；
* 不做炼化；
* 不做法宝合成；
* 不做宠物系统；
* 不做战斗助战；
* 不做拘灵养成。

## 十一、Boss 战如何承载这些系统

第一章 Boss 战不能变成单纯堆系统。

这些系统必须被编排进一条体验曲线：

### 阶段一：凡木入山

玩家手持凡木棍进入悟道山门。

体验重点：

* 凡人感；
* 武器存在；
* 山门压迫。

### 阶段二：引气入器

玩家按 Q，将灵气传导到木棍。

体验重点：

* Q 灵气传导；
* 五行附灵；
* 灵根进入战斗。

### 阶段三：环境借法

玩家用附灵攻击触发场地元素反应。

体验重点：

* 元素反应 V0；
* 世界规则可互动；
* 修仙不是单纯挥砍。

### 阶段四：石傀登场

Boss 出现，普通攻击效果有限。

体验重点：

* Boss 压迫；
* 破势需求；
* 附灵不是装饰。

### 阶段五：破势战斗

玩家通过 Q 附灵、E 神通、环境反应打破 Boss 势。

体验重点：

* Q 是基础循环；
* E 是爆发；
* 命格被动静默影响打法。

### 阶段六：凡器折断

Boss 半血 / 特定阶段重击，木棍折断。

体验重点：

* 武器耐久 / 折断雏形；
* 战斗转折；
* 凡器有尽，道心不折。

### 阶段七：拾残兵再战

玩家拾取石傀断臂 / 山门旧剑。

体验重点：

* 武器更替；
* 新武器可继续附灵；
* 灵气来自玩家，不来自武器。

### 阶段八：拘灵收尾

Boss 被击败，命书拘入土行残灵。

体验重点：

* 拘灵系统 V0；
* 战利品可查看；
* 第一章成长闭环。

## 十四、Codex 红线

后续给 Codex 时必须写清楚：

1. 第一章是系统 V0，不是完整版。
2. 不允许实现完整元素矩阵。
3. 不允许实现元素状态叠加。
4. 不允许实现完整武器背包系统。
5. 不允许实现武器锻造、强化、词条。
6. 不允许实现多神通切换。
7. 不允许实现神通升级。
8. 不允许实现命格树。
9. 不允许实现拘灵召唤 / 变身 / 养成。
10. 不允许实现商店、交易、分解、合成。
11. 所有系统必须只服务第一章悟道山试炼。
12. 所有新增内容必须有明确验收标准。
