# 8. 五问定心固定版

## 8.1 设计目标

五问定心不是普通问卷，而是开局仪式。

五问必须决定：

```text
主灵根
灵根品质
副灵根
命格
初始属性倾向
初始术法
初始灵气附魔方向
第一章战斗风格
```

从本版本开始，五问文案以本节为准，后续只允许微调，不再反复改版本。

## 8.2 重要计算原则

最终采用：

> 第二问决定主灵根。
> 其他四问决定共鸣度、副灵根、命格和战斗倾向。

不再采用“所有问题直接累加元素分来决定主灵根”的方式。

原因：

* 第二问才是真正问灵根。
* 其他问题更多是问道心、凡尘、应敌、入世。
* 天灵根 / 纯灵根不能只靠单题判断，而要看主灵根与后续选择是否共鸣。
* 这样更符合修仙设定，也避免某些灵根因为问题分布不均而天然吃亏。

# 9. 五问结果计算规则

## 9.1 主灵根

主灵根只由第二问决定。

```text
q2_a → 金灵根 metal
q2_b → 木灵根 wood
q2_c → 水灵根 water
q2_d → 火灵根 fire
q2_e → 土灵根 earth
```

## 9.2 共鸣度

其余四问，即第一问、第三问、第四问、第五问，根据选项共鸣标签判断是否与主灵根共鸣。

规则：

```text
如果选项 resonanceTags 包含主灵根，则 resonanceCount +1。
如果选项 resonanceTags 包含 primary，则 resonanceCount +1。
如果选项 resonanceTags 只包含 dao，不加主灵根共鸣，但增加道心倾向。
```

共鸣度范围：

```text
0 ~ 4
```

## 9.3 副灵根

副灵根由其余四问中出现最多的非主灵根标签决定。

例如：

```text
主灵根：金
其余选择中 wood 出现 2 次
则副灵根候选为 wood
如果达到双灵根条件，则显示为金木双灵根。
```

## 9.4 灵根品质算法

最终规则：

```text
共鸣 4 次，且副灵根干扰很低：天灵根
共鸣 3 次，且副灵根干扰不高：纯灵根
共鸣 2 次，且副灵根出现 2 次以上：双灵根
共鸣 2 次，但副灵根不明显：纯灵根偏弱
共鸣 1 次，副灵根明显：双灵根或杂灵根
共鸣 0~1 次，选择分散：杂灵根
共鸣 0~1 次，但 dao / persistence 很高：凡灵根 / 凡骨问道
```

建议可执行伪代码：

```js
function calculateRootResult(primaryElement, selectedOptions) {
  let resonanceCount = 0
  const secondaryCounter = {
    metal: 0,
    wood: 0,
    water: 0,
    fire: 0,
    earth: 0
  }

  let daoScore = 0
  let persistenceScore = 0

  for (const option of selectedOptionsWithoutQ2) {
    const tags = option.resonanceTags || []

    if (tags.includes(primaryElement) || tags.includes("primary")) {
      resonanceCount += 1
    }

    if (tags.includes("dao")) {
      daoScore += 1
    }

    if (option.trait === "persistence") {
      persistenceScore += 1
    }

    for (const tag of tags) {
      if (secondaryCounter[tag] !== undefined && tag !== primaryElement) {
        secondaryCounter[tag] += 1
      }
    }
  }

  const secondaryElement = getHighestSecondaryElement(secondaryCounter)
  const secondaryScore = secondaryCounter[secondaryElement] || 0

  if (resonanceCount >= 4 && secondaryScore <= 1) {
    return { rootQuality: "heaven", primaryElement, secondaryElement: null }
  }

  if (resonanceCount >= 3 && secondaryScore <= 1) {
    return { rootQuality: "pure", primaryElement, secondaryElement: null }
  }

  if (resonanceCount >= 2 && secondaryScore >= 2) {
    return { rootQuality: "dual", primaryElement, secondaryElement }
  }

  if (resonanceCount >= 2) {
    return { rootQuality: "pure", primaryElement, secondaryElement: null }
  }

  if (daoScore + persistenceScore >= 2) {
    return { rootQuality: "mortal", primaryElement, secondaryElement: null }
  }

  return { rootQuality: "mixed", primaryElement, secondaryElement }
}
```

说明：

* `heaven`：天灵根
* `pure`：纯灵根
* `dual`：双灵根
* `mixed`：杂灵根
* `mortal`：凡灵根 / 凡骨问道

## 9.5 命格计算

命格由第一问、第三问、第五问为主，第四问为辅助。

命格列表：

| 命格   | 来源倾向          | 文案气质      |
| ---- | ------------- | --------- |
| 凡骨问道 | dao / 均衡 / 求道 | 凡身入山，问心不退 |
| 孤锋入世 | metal / 勇决    | 一剑破障，不问归途 |
| 厚土守心 | earth / 坚韧    | 心如山岳，稳步登仙 |
| 青木长生 | wood / 仁心     | 生机不绝，护己护人 |
| 流水观心 | water / 洞察    | 进退有度，以静制动 |
| 烈火破妄 | fire / 执念     | 一念燃心，破妄开路 |

推荐规则：

```text
如果 dao 标签和 persistence 倾向较高 → 凡骨问道
如果 metal / courage 倾向最高 → 孤锋入世

```

# 10. 灵根系统

## 10.1 灵根组成

灵根由两部分组成：

```text
灵根属性：金 / 木 / 水 / 火 / 土
灵根品质：天灵根 / 纯灵根 / 双灵根 / 杂灵根 / 凡灵根
```

第一章必须显示灵根属性与品质，让玩家感到五问选择有分量。

## 10.2 灵根品质定义

### 天灵根

含义：

> 单一五行极强，灵气亲和极高。

特点：

```text
主元素术法伤害高
主元素附魔效果强
灵力恢复快
成长方向极清晰
```

### 纯灵根

含义：

> 主灵根明确，但未到天灵根程度。

特点：

```text
主元素技能稳定
附魔效率较高
成长方向清晰
比天灵根更平衡
```

### 双灵根

含义：

> 两种五行接近，灵气可互相牵引。

特点：

```text
更早触发元素反应
单一元素威力低于纯灵根
战斗玩法更灵活
```

示例：

```text
金火双灵根：锋锐 + 爆发
水木双灵根：迟缓 + 生长
土金双灵根：防守 + 破甲
```

### 杂灵根

含义：

> 五行皆有，但不纯。

特点：

```text
前期术法较弱
灵力控制不稳定
后期可走五行反应流
第一章不应惩罚太重
```

### 凡灵根 / 凡骨问道

含义：

> 灵根不显，但道心坚定。

特点：

```text
不是废号
是主线正统命格之一
初始数值平衡
附魔普通
体魄和韧性略补偿
成长叙事更强
```

## 11.4 属性加成计算规则

第一章所有百分比加成使用加法，不使用乘法。

示例：

```js
finalLightAttackDamage =
  baseLightAttackDamage *
  (1 + elementBonus + rootQualityBonus + statusBonus)
```

不要使用：

```js
base * (1 + elementBonus) * (1 + qualityBonus) * (1 + statusBonus)
```

取整规则：

```js
finalDamage = Math.round(finalDamage)
finalDamage = Math.max(1, finalDamage)
finalHeal = Math.round(finalHeal)
```

加成上限：

```text
单次伤害加成最高不超过 +50%
单次减伤最高不超过 -35%
单次减速最高不超过 -40%
```

# 13. 初始术法与 Q 键定义

## 13.1 初始术法名称

| 灵根 | 初始术法 |
| -- | ---- |
| 金  | 金芒刺  |
| 木  | 青藤缚  |
| 水  | 寒流刃  |
| 火  | 赤焰诀  |
| 土  | 岩心印  |

## 13.2 Q 键不只是普通技能

第一章主角尚未正式入门，没有具体功法。

因此 Q 键定义为：

> 基础灵气调动。

Q 的作用不是单纯“发一个技能”，而是让玩家调动灵气，进入短暂的灵气凝聚状态。

## 13.3 Q 键机制

```text
按 Q 后，玩家进入 enchant_ready / 灵气凝聚状态。
持续约 3 秒。
消耗 15 MP。
3 秒内下一次左键或右键攻击，会变成对应主灵根的附魔攻击。
如果 3 秒内没有攻击，则灵气外放为弱灵气团或自动消散。
Q 冷却 5 秒。
Q 冷却期间不能再次进入附魔。
```

第一章不做元素自由切换。

规则：

```text
玩家只能使用五问结果对应的主灵根附魔。
双灵根第一章默认使用得分最高的主灵根，第二灵根只用于结果页显示和后续扩展。
Q 冷却期间不能再次附魔。
附魔准备状态期间再次按 Q 无效果，只提示“灵气尚未平复”。
```

# 15. 灵气附魔系统

## 15.1 系统定位

灵气不只是放技能。

第一章中，玩家没有功法，因此灵气主要有三种粗浅用法：

```text
外放成灵气团
附着在武器上
附着在身体上形成护体
```

## 15.2 附魔定义

附魔是：

> 玩家将自身灵气暂时附着到武器、身体或环境物上，使普通动作带有五行效果。

第一章优先实现：

```text
武器附魔
身体护体
```

环境附魔后续扩展。

## 15.3 附魔攻击示例

### 金附魔轻击

```text
木剑边缘出现淡金剑芒。
攻击范围略微变长。
对石傀 / Boss 护体造成额外破防。
```

### 火附魔重击

```text
木剑燃起火光。
重击命中后造成燃烧。
伤害高，但附魔持续短。
```

### 木附魔轻击

```text
木剑生长一截。
攻击距离增加。
命中后短暂缠绕敌人。
```

### 水附魔攻击

```text
剑身带水纹。
命中敌人后造成迟缓。
可轻微延缓敌人下一次攻击。
```

### 土附魔

```text
身上出现金色护体。
下一次受击减伤。
下一次重击带震荡。
```

## 15.4 附魔消耗规则

```text
一次轻击动作消耗一次附魔。
一次重击动作消耗一次附魔。
如果未来做三连击，每一段攻击动作单独消耗一次附魔。
第一章暂不做连击系统，保留接口即可。
```

# 16. 元素反应系统

## 16.1 设计目标

元素反应是后续战斗深度核心。

但第一章主角修为低，不能一开始就大范围爆炸、连锁反应。

第一章规则：

> 修为低时，元素反应轻微；修为越高，元素反应越明显、越复杂、越强。

## 16.2 元素状态

| 状态               | 来源 | 效果          |
| ---------------- | -- | ----------- |
| metal_break / 破甲 | 金  | 降低防御或提高受到伤害 |
| wood_bind / 缠绕   | 木  | 限制移动或延展木质物  |
| water_slow / 迟缓  | 水  | 降低移动或延迟攻击   |
| fire_burn / 燃烧   | 火  | 持续伤害        |
| earth_guard / 护体 | 土  | 护体、震荡、碎裂    |

## 16.3 第一章必做反应

### 金 + 土：破石 / 破甲

目标：

```text
金附魔命中土行石傀或 Boss 时，造成额外破甲伤害。
```

效果：

```text
额外伤害 +15%
播放金色破甲闪光
Boss / 石傀身上出现短暂裂纹特效
```

### 水 + 土：泥泞 / 迟缓

目标：

```text
水附魔命中土行石傀或 Boss 时，造成短暂减速。
```

效果：

```text
移动速度降低 25%
持续 1.2 秒
Boss 红圈预警若正在进行，可延长 0.15 秒爆发时间
```

### 火：燃烧

目标：

```text
火附魔命中目标后造成燃烧 DoT。
```

效果：

```text
持续 2 秒。
每 0.5 秒造成 2 点伤害。
若目标已有 wood_bind 状态，则燃烧伤害提高。
```

## 16.4 第一章结构预留

以下反应第一章不强制做完整效果，只需数据结构或注释预留：

```text
水 + 火：蒸汽 / 熄灭
木 + 土：根裂 / 生长破土
```


## 24.8 Boss 受击与霸体

普通受击：

```text
Boss 在 idle / walk / attack_recovery 状态下被命中，会播放受击闪光。
轻击只造成闪光和轻微停顿，不强打断。
重击可造成 0.18 秒微硬直。
附魔重击可造成更明显反馈。
```

霸体状态：

```text
Boss 在 attack_startup / attack_active / phase_transition / dead 状态下拥有霸体。
霸体期间受到伤害，但不会被打断。
红圈震地和山门镇压期间 Boss 不会被轻击打断。
```

破绽窗口：

```text
Boss 每次攻击后的 attack_recovery 是玩家主要反击窗口。
重砸和山门镇压后的破绽更长。
```

## 24.9 Boss 阶段

阶段一：

```text
血量：100% ~ 50%
使用：慢步逼近、横扫普攻、重砸、少量红圈震地
```

阶段二：

```text
血量：50% 以下
攻击频率略微提高
红圈震地概率提高
解锁山门镇压
Boss 身上出现金色土行护体光
BossHUD 可变色或闪烁
```

## 24.10 Boss 出招逻辑

```text
如果 Boss 正在攻击、受击、死亡、阶段转换：
    不选择新招式

如果玩家距离 < 80 px：
    优先横扫普攻
    如果重砸冷却可用，有 30% 概率重砸

如果玩家距离 80~180 px：
    优先重砸
    如果红圈可用，有 25% 概率红圈震地

如果玩家距离 > 180 px：
    慢步逼近
    如果红圈可用，有 35% 概率红圈震地

如果 Boss 血量 <= 50%：
    进入阶段二
    红圈概率提高
    山门镇压加入候选技能
```

山门镇压限制：

```text
山门镇压只在阶段二释放。
冷却 14 秒。
阶段二进入后的前 3 秒不释放，给玩家反应时间。
同一场 Boss 战中，两次山门镇压至少间隔 14 秒。
山门镇压后 Boss 有 1 秒明显硬直。
```


```text
回到标题界面。
localStorage 中可保留五问结果。
```

# 34. 资源加载失败处理

如果资源加载失败，不允许游戏白屏。

规则：

```text
背景加载失败：使用纯色国风渐变背景。
玩家 sprite 加载失败：使用临时半 Q 图形角色。
Boss 加载失败：使用土金色大型占位 Boss。
技能图标加载失败：使用文字 + 国风边框占位。
音效加载失败：静默跳过，不阻塞游戏。
```

控制台输出清晰警告。

# 36. Codex 执行原则

所有 Codex 任务必须遵守：

1. 先读 PRD。
2. 先列新增 / 修改文件清单。
3. 每次只做一个明确模块。
4. 不扩新系统。
5. 不大范围重构。
6. 不随便改操作方式。
7. 不用“第一版”作为低质量借口。

9. 修改后必须 `npm run build` 成功。
10. 输出验收步骤。
11. DOM 不能拦截战斗输入。
12. 美术资源必须区分参考图和可用素材。
13. 角色动画必须预留 sprite sheet 结构。
14. Q 键必须按“灵气调动 / 附魔入口”设计，不只是普通技能。
15. 第二问决定主灵根，其他四问决定共鸣度，不得改回简单总分决定灵根。

# 39. 版本结论

《寻仙问道：悟道山试炼》第一章的核心不是“快速做一个可玩 Demo”，而是：

> 通过五问定心建立命格与灵根，通过灵气附魔建立修仙战斗差异，通过轻量元素反应建立后续系统深度，通过土行石傀完成教学，通过山门守卫 Boss 完成第一章战斗闭环。

第一章必须以作品化标准推进。
