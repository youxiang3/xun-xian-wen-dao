# 《寻仙问道》阶段式开发规则

## 总原则

本项目按剧情阶段和功能阶段推进，不允许一次性实现完整游戏。

## 第一阶段目标

第一阶段为：

五问定心 → 天命降世 → 入世十六载 → 悟道山试炼 → 入仙门

## 当前 Web Demo 阶段任务

推荐阶段：

1. Task 01：项目初始化
2. Task 02：标题界面
3. Task 03：完整五问定心 + 问心结果页
4. Task 04：天命降世 + 入世十六载
5. Task 05：悟道山试炼场 + 玩家移动 + HUD
6. Task 05.6：Player 逻辑与视觉分离
7. Task 06：基础战斗输入 + 五行攻击术
8. Task 07：小怪教学 + 命中反馈
9. Task 07.7：玩家死亡 / 试炼失败 / 小怪教学完成提示
10. Task 08：悟道山试炼守卫 Boss
11. Task 09：Boss 击败后第一阶段结束
12. Task 10：第一章整体打磨

## 禁止提前实现

未到对应 Task 前，不要实现：

- Boss
- Boss 红圈
- 胜利结算
- 联网
- 背包
- 装备
- NPC
- 任务系统
- 散市
- 大唐地图
- 西游路
- 正式美术资源
- 复杂音频资源
