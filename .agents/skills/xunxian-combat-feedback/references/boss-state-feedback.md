# Boss State Feedback

## Boss 状态

- `Normal`
- `Hurt`
- `Stagger`
- `ArmorBroken`
- `Burning`
- `Wet`
- `WoodBind`
- `Slowed`
- `Enraged`
- `Dead`

## Boss 受击表现

- 金：破甲 / 金光裂纹。
- 木：藤蔓缠绕。
- 水：湿润 / 蓝色水雾。
- 火：灼烧 / 火星。
- 土：击退 / 地裂。
