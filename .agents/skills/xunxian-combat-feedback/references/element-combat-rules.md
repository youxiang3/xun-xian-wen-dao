# Element Combat Rules

## 五行颜色

- 金：金色，建议 `#F5D76E`。
- 木：青绿色，建议 `#4CCB6B`。
- 水：蓝色，建议 `#58B7FF`。
- 火：橙红色，建议 `#FF5A3D`。
- 土：土黄色，建议 `#B88A4A`。

## 五行术法

- 金芒刺：金属性穿刺，偏破甲表现。
- 青藤击：木属性束缚，偏藤蔓缠绕表现。
- 寒露刃：水属性冷冽切割，偏湿润和水雾表现。
- 火星诀：火属性灼烧，偏火星和燃烧表现。
- 碎土刺：土属性冲击，偏击退和地裂表现。

## 相克关系

- 金克木。
- 木克土。
- 土克水。
- 水克火。
- 火克金。

## 状态

- `Wet`：湿润，可作为水属性命中后的状态。
- `Burning`：燃烧，可作为火属性持续反馈。
- `Slowed`：减速，可由水或土相关效果触发。
- `WoodBind`：木缚，可限制移动或表现为藤蔓缠绕。
- `MetalBreak`：金破，可表现为破甲或防御下降。

## 组合预留

- 水 + 火 = 蒸汽。先预留视觉和状态扩展入口，不必提前实现完整组合系统。
