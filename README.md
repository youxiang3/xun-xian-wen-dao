# 寻仙问道：悟道山试炼 Web Demo

当前进度：Task 07.7，玩家死亡 / 试炼失败 / 小怪教学完成提示。

项目使用 Phaser + TypeScript + Vite。当前版本已实现标题界面、完整五问定心、问心结果页、天命降世过场、入世十六载过场、悟道山试炼场、玩家移动、CombatHUD、SkillSlotHUD、基础战斗输入、资源消耗与恢复、五行基础攻击术表现、小怪教学、命中判定、基础打击反馈、页面画布适配、战斗可视性增强、玩家死亡状态、试炼失败 UI 和小怪教学完成提示。

## 安装

```bash
npm install
```

如果本机 npm 外部缓存权限报错，可使用：

```bash
npm install --cache .npm-cache
```

## 启动

```bash
npm run dev
```

默认本地地址：

```text
http://localhost:5173/
```

## 构建

```bash
npm run build
```

## Task 07.7 说明

- 玩家 HP 到 0 后进入 Dead 状态，HP 固定为 0。
- 死亡后禁止移动、轻击、重击、Q、闪避、回血。
- 玩家死亡后显示“试炼失败 / 凡骨未定，道心未折。/ 点击重新开始”。
- 点击失败 UI 后重启 `GateTrialScene`。

- 本阶段不触发 Boss，不做胜利结算。

## 验收提示

1. 运行 `npm run build`，确认构建成功。
2. 运行 `npm run dev`，打开本地页面。
3. 从标题页完成五问、结果页和两个过场。
4. 进入悟道山试炼场，确认出现一只小怪。
5. 靠近小怪，确认小怪追踪并攻击玩家。
6. 让小怪击败玩家，确认 HP 不低于 0，并出现试炼失败 UI。
7. 玩家死亡后尝试移动、攻击、Q、闪避、回血，确认不再响应。
8. 点击失败 UI，确认重新开始悟道山试炼场。
9. 击杀小怪，确认出现“试炼影妖已灭。继续向山门前行。”。
